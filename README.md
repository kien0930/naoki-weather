# naoki-weather

Số liệu thời tiết thật (nguồn: [Open-Meteo](https://open-meteo.com/), giấy phép CC BY 4.0) cho 8 thành phố, tự kiểm tra mỗi 5 phút bằng GitHub Actions.
Trang trợ lý Live2D Hanamura Naoki đọc file `weather.js` qua jsDelivr để biết trời nóng, mưa hay lạnh mà tự thay đồ.

Thành phố: Sài Gòn, Cần Thơ, Hà Nội, Hải Phòng, Huế, Đà Nẵng, Nha Trang, Đà Lạt.
